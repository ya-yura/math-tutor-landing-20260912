# Лендинг репетитора по математике

Одностраничный адаптивный лендинг на чистом HTML, Tailwind CSS и минимальном JavaScript для учеников 5—8 класса.

Демо: https://ya-yura.github.io/math-tutor-landing-20260912/

## Локальный запуск

```bash
npm install
npm run build
npm run start
```

После запуска откройте `http://localhost:4173`.

## Структура

- `src/index.html` — семантическая разметка и тексты лендинга.
- `src/input.css` — Tailwind CSS и небольшие брендовые стили.
- `src/script.js` — мобильное меню и 4-шаговый квиз с отправкой квалифицированной заявки в Telegram Share.
- `public/portrait.png` — предоставленный заказчиком портрет.
- `dist/` — production-сборка, создаётся командой `npm run build`.

## Важные настройки перед публикацией

- В форме используется Telegram Share, потому что личный Telegram username, телефон и сервер для обработки заявок не были предоставлены. Для прямых заявок можно заменить ссылку в `src/script.js` на username или подключить CRM/form endpoint.
- Точная стоимость и фактические цифры динамики не были предоставлены, поэтому на странице указано, что стоимость фиксируется после диагностики, а блок результатов оформлен как ориентиры траекторий, а не как подтверждённые кейсы.
- Адрес для очных занятий отсутствует в доступных материалах. Яндекс-карта не подключена, чтобы не публиковать ложную точку; после получения подтверждённого адреса её можно добавить в блок контактов.

## Проверки

- Production-сборка выполняется через Tailwind CLI.
- Основные CTA ведут к единой форме `#lead-form`.
- Форма требует имя, контакт и цель; после отправки открывает Telegram с готовым сообщением.
- Есть адаптивная навигация и мобильная sticky-кнопка.
